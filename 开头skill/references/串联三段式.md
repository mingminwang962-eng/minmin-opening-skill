# 串联三段式（写完口播开头主体、确定怎么零报幕停刀咬进正文第一句时必读）

> **交付协议**：每套口播成品 ＝ **开头主体（在最高张力处按 G1～G4 停刀！） ＋ 可选 ≤8 字纯口语微关节（默认首选零桥直进！） ＋ 接回原稿的具体口播首句**。给出准确原句、位置及前置内容删留；底稿含书面小标题时提示口播跳过小标题直读首句。
> **反报幕与反污染死线**：252 篇真实口播爆款末尾出现*“往下看 / 往下听 / 从头说起 / 下面我逐个拆开 / 先从XX说起 / 一招一招拆给你”*的比例为 **`0.0%（0/252）`**！**永久禁止在开头末尾加任何主持人报幕废话尾巴**，也严禁在 `态 C` 私域交底中出现“刷到的朋友/先点关注”等公域算法词！

## 一、核心校准：G1～G4 幕断悬停 × 正文首句接力配对（零桥直进优先！）

**零桥直进的本质，是“开头停在悬念缺口最大处，让正文第一句直接当接力棒”！** 参照下方 **4 种零报幕幕断咬合对** 让开头末句与正文首句无缝咬死：

| 开头末句幕断算子（怎么停刀？） | 正文第一句接力形态（怎么接球？） | 适用口播态与红线 |
|---|---|---|
| **G1 · 核心词 / 稀缺解法冒号亮牌停刀**<br>（最后半拍直接点出核心概念名或稀缺方法名即停） | 正文首句直接接原稿的 **`什么是 [该词]？`**、概念白话拆解句或第一步动作 | 态 A/B 高频王牌；**严禁在冒号亮牌后再画蛇添足补“下面我给你拆解”** |
| **G2 · 锋利金句 / 成对爽感原话重锤停刀**<br>（占全库 77.8%！最后一句停在最扎心断言或作者成对体感原话上） | 正文首句直接撞进原稿的**常见错法靶子（`很多人以为…`）、具体案例人物、或原稿自带的 `那具体怎么做到？`** | 全态通用；重锤落地即进正文，多补半句过渡都会泄掉锤感！ |
| **G3 · 数量总契约 / 对号标尺干脆封口**<br>（≤12 字报清总件数或对号选配规则，如*“累分三种，按情况对号选就行。”* / *“今天说透这件事，就三点。”*） | 正文首句零废话直接进原稿 **`第一种，…` / `第一件事，…`**（若底稿前有 `### 一、XX` 书面标题，提示口播跳过小标题直念首句） | 多招方法稿专属；**报完“分三种/就三点”立刻封口，严禁再拖“下面我挨个拆”！** |
| **G4 · 反差账单 / 特稿转轨句（The Turn）悬停**<br>（停在惊人收益结果、真实对赌或 `A7` 故事折返后的共性判断上） | 正文首句直接进**亲历起点、实验第 1 天或第一个被忽略的关键环节** | `A2/A7` 专属；`态 B` 长深度口播若确有现成开源工具/大纲资产，可直亮实物资产封口 |

### 附：全口播三态接头边界与「候选 4 两拍跨尺度短刀」落回法
1. **态 A（短视频口播 ＜3 分钟）**：**90% 走零桥直进**；仅当视角跳跃大时，允许加 **≤8 字纯口语微关节**（见下节），禁塞“今天这条视频给大家讲讲”慢热废话。
2. **态 B（中长深度口播 ≥5 分钟）**：仅当正文确有复杂路线或现成工具且有助理解时，才自然交代真实准备量或交付范围，绝不按字数硬吹承诺。
3. **态 C（私域 1v1 交底口播 / 语音说明信）**：平视交底立住“我是谁＋在做之事＋无套路边界”后，直接自然接原稿第一板块首句，禁用推销腔与公域算法词。
4. **候选 4（1～2 句跨尺度破圈短刀）落回垂直正文首句防断档法**：当短刀第 1 拍站在 Scale 3 全民母题时，**第 2 拍句尾必须精准落在原稿的核心概念词、单点心锚或总件数锚词上**，使紧接的原稿第一句刚好承接该锚词（若原稿首句过陡，可配 ≤6 字纯口语微关节如*“先看第一点” / “为什么这么说？”*顺滑落回）。

## 二、确需加桥时的 4 类「无实词纯逻辑微算子」

当零桥直进略显突兀时，只允许按**纯逻辑关系**生成一句紧贴本稿语境的超短关节（不预设任何固定词壳）：
1. **反预期急刹算子**：在受众以为要按常规套路行动时，用极短半句叫停惯性动作，引出下文真正的第一步。
2. **可复制归因算子**：仅当正文教授路径且有成因证据时，点明下文要拆解的路径、工具或环境条件；否则直接接结果的真实意义、困惑或后续。适用条件见主文件 A2。
3. **具象落点切入算子**：在首句给出宏观洞察之后，顺势切入本稿中的某一个具体业务场景、真实人物或日常动作。
4. **看点指认算子**：在展示完反面话术扮演或具体产物之后，直接点出刚才那一幕里最值得注意的关键细节。

## 三、承接四条铁律（交稿前必核）

1. **下一句增量承接铁律（最高优先级）**：内部连读开头与接回的完整一段，检查推进、指代与遗漏。对外标明准确原句、位置及前置内容原位删留；默认保留正文次序、仅处理重复句；跨段跳接须逐项核对被跳过内容，不能用主旨概括替代原有论据或区分。执行以主文件终检第 7 项为准。
2. **情绪与语域温度连贯**：开头与接回的正文首句保持同一说话呼吸——开头松弛平视，正文首句不突然端起教科书定义架子；开头犀利破题，正文首句立刻给硬核实证。
3. **末句能接入后文**：可以先给结论，再用正文解释或举证；不要为了悬念隐藏必要信息，也不要无故用总结套话结束。
4. **保留原稿自然落点**：具体事实、动作、核心判断或必要概念说明均可承接；不为凑具体物改写事实，避免只有空泛宣告。

## 五、接回正文第一句的八种标准语义落点

1. **具体人物 / 亲历节点登场**：直接带出原稿中的真实案例主角或作者关键时间节点的具体处境；
2. **极短底牌先行**：用一句不绕弯的核心判断破门，随后再展开原稿论据；
3. **分步 / 清单首项直进**：方法与说明书类文稿，直接落入第一条具体动作或第一个板块；
4. **常见错法靶子切入**：先点出大多数人在该场景下的习惯性错误动作及其后果；
5. **真实成本 / 时间账单切入**：用原稿里的具体数字或投入产出对比开启论证；
6. **高颗粒度感官现场切入**：带具体时间、场景与动作细节推进叙事；
7. **原生概念白话拆解切入**：紧接开头抛出的那个核心词，用原稿事实把它的具体指向拆明白；
8. **客观实验 / 观察样本托底**：直接端出原稿已有的研究发现或大样本观察事实。
