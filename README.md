# min-开头

3个完整口播开头，和1个极简短版。

官方安装与使用：https://tools.minmin11538.cn/opening/

## 装好后直接发

```text
用 min-开头，给下面这篇稿子写开头：

〔在这里粘贴你的完整正文〕
```

有“技能／使用技能”按钮时，也可选中「min-开头」后直接贴稿；只有宿主实际支持时才用斜杠快捷入口。需要刷新技能清单时先新开对话。交出3个完整口播开头＋1个极简短版，以及各自接回正文的位置或第一句。

本包首次完整安装分别提供min-开头和开头身份梳理。身份梳理可选，不要求先建档；旧单目录更新器不会自动安装附带身份技能，要使用时请用官网完整安装口令补齐。

实际安装说明见[INSTALL.md](INSTALL.md)。未实际调用时保留待验证状态，下载或解压不代表首次使用通过。

## 使用边界

AI表达仍需创作者核对事实与原意，尤其不要补写未提供的态度、经历或成功因果。测试只支持已记录场景，不是传播效果保证。用户档案留在自己机器上，不在Skill包内。
