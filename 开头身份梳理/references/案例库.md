## 当前组合示范：同一人物，按受众筛三种用途

原料来自下方老陈完整校准档案：现在经营社区面包店，过去做过五年餐饮督导、巡过180家加盟店；开店初期亏过三万房租，后来靠街坊复购经营。假定本例受众是想开社区小店、怕加盟和经营踩坑的人，向往小而稳的经营状态。

| 用途与受众 | AI重新组合的短句（逐字计数≤20） | 组合思路 |
|---|---|---|
| 通用介绍／想开社区小店的人 | 做过五年餐饮督导的社区面包店主 | 从业经验＋当前角色 |
| 加盟避坑／考虑加盟的人 | 巡过180家加盟店，现开社区面包店 | 经手样本＋当前实践，说明观察从哪里来 |
| 创业复盘／担心亏损的人 | 亏过三万房租，靠街坊复购的小店主 | 弯路＋经营方式＋当前角色 |

这些句子由AI结合完整事实与受众用途写出，不要求本人原文逐字出现。三版用途不是固定分类；不因有学历就必出学历版，也不因没钱就缺少身份资料。不得把“巡店”写成“本人开过180家店”，也不凭街坊复购补造新的利润或因果。

**比较后再选**：只摘“做过餐饮督导”会丢掉年限与当前小店角色；只摘“亏过三万房租”会丢掉现在的经营状态。若同句放得下，优先选择上表组合。相关标签已很多时，要靠取舍与组织提升密度，不能只把三份原料各自缩短就算完成。

### 无数字、无强反差也能成立（新增语义校准）

- **已给事实**：「我在社区做社工，常陪老人办事、处理家属沟通；自己也在照顾失能家人，面对镜头容易紧张。想讲照护和家属沟通，不记得量级，也不想公开数字。」
- **可收资料**：「社区社工，也在照顾失能家人，熟悉办事和家属沟通中的两难。」这是职业与家庭角色共同形成的相关经验，不需要编造年限、服务人数或成功结果。
- **可收卡点**：「讲照护和家属沟通时仍会镜头紧张。」不能改成“已经克服紧张”。
- **不强填**：没有提供收入、工具或实测成绩，D2、D4可留白；不为了填满五格要求补做挑战。
- **使用示范**：「照护中的沟通难处，我在社区工作和照顾自己家人时都遇到过。」不加“靠这套方法解决了全部矛盾”等未提供的因果。

**收资料与写开头分两步判断**：本人亲手做出的代表工具可以作为D4候选；但在具体开头里，“我做了一个工具”若仅是在介绍产品功能，不自动等于有效身份植入。反之，“我们导演组”虽没直接报岗位，也可能在上下文里建立从业者位置。完整语义优先，不能靠关键词决定。

## 二、怎么写「上身效果示范」与第 3 列用法提示？（全程说大白话）

身份可以在判断后当论据，也可以在转入正文时交底。**当前默认只交三版短句；以下保留的长示范仅用于理解身份与观点怎样相接，用户明确要求看完整开头时才示范。**原例长身份段不满足当前20字成品要求，需要重新取舍组合；不能因为示范而恢复默认五格长表＋两段开头。

1. **证明方法真有效（用 D2 / D4）**：
   - 上身示范：「下班后想攒下第二份收入，千万别靠熬夜硬肝体力活。**因为我就是在互联网公司全职上班的情况下，纯靠下班两小时搭对复利流程，两年半攒下了28万。**」
   - 第 3 列人话写法：`需要相关实践依据时顺势带出；只有用户原稿确有依据，才把结果归因于本篇方法，不凭一条成绩编造成因。`
2. **用工位见闻立内行权威（用 D1 / D3）**：
   - 上身示范：「做账号最怕的不是没爆款，是一上来用力过猛。**我干了四年运营、经手四十多个号，亲眼见过太多IP前三十条风风火火，掏空存货后直接烂尾。**」
   - 第 3 列人话写法：`讲行业避坑题时放第2句或进正文前当一线亲眼见过的证据，别放第一句干报岗位；分清“经手见过”与“个人操盘成交”，不夸大。`
3. **半句资历垫底秒切暴论（用 D1 / D3）**：
   - 上身示范：「**当了十四年设计老师、带过上万名学生后**，我得出一个扎心结论：决定你能不能拿高薪的，从来不是软件熟练度。」
   - 第 3 列人话写法：`用前半句十来个字带出从业年限，后半句立刻接反常识判断，干净利落不啰嗦。`
4. **先证不笨、再认栽拉近距离（用 D1/D2 ＋ D5）**：
   - 上身示范：「为什么职场优等生出来单干十有八九会栽？**我自己就是活靶子：普通二本毕业两年拿上市公司税后1.8万，自以为很懂业务，结果裸辞做一人公司前一年半几乎全白干。**」
   - 第 3 列人话写法：`讲转型踩坑题时搭配 D1 一起用——前半句证明职场干得不错，后半句坦白换赛道栽过跟头；纯聊焦虑内耗或新手卡点时只用 D5 共情，严禁晒大钱。`
5. **替大家干苦活 / 同处境说实话（用 D3 / D4 / D1）**：
   - 上身示范：「网上都在传读三百本书就能赚大钱，我偏不信——**专门花两周翻烂了他过去四年发的全部320篇旧笔记**，发现真正让他起飞的根本不是读书。」
   - 第 3 列人话写法：`没头衔时直接亮出替大家干完的苦功夫或同为在职/带娃的真实处境，一秒建立信任。`
