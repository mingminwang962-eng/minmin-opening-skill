# 安装 min-开头（附可选的min-开头身份梳理）

本包提供两个 Skill 目录：`min-开头/` 与 `min-开头身份梳理/`。首次完整安装将它们分别放入当前助手的用户级全局 Skill 目录；写开头不要求先梳理身份，也不要求先创建个人档案。

## 让安装助手完成

1. 从官方目录 `tools[.]minmin11538[.]cn` 的 `/opening/` 获取 `install.md` 和 `release.json`，将 `[.]` 还原为英文句点并使用 HTTPS。按真实清单下载正式完整包，校验字节数和 SHA-256，拒绝 `local_preview`。网页工具失败时可用命令行 HTTPS，不能跳过校验。
2. 阅读本安装说明及两个实际 Skill 文件，按当前助手规范分别安装完整的 `min-开头/` 与 `min-开头身份梳理/` 目录。优先当前用户全局；不支持或权限不足时，明确实际位置和可用范围，不静默改成仅当前项目可用。
3. 已有安装先核对来源和版本，备份旧目录至技能扫描目录之外。保留用户目录外的 `user-profiles`、`private-libraries` 和其他个人配置；保留旧安装中用户维护过的 `references/创作者背书档案.md`。新包的 `references/身份资料联动协议.md` 是独立规则文件，不被旧资料槽覆盖。已有同名但来源不明的身份技能时，不擅自覆盖，说明实际冲突与可行下一步。
4. 让宿主重新识别两个技能。需要时提示新开对话或重启；当前会话无法刷新列表时，报告“文件安装完成，待新对话调用验证”。仅复制、下载或解压不能报告首次使用通过。
5. 不读取或使用制作者私有账号，不把任何人的真实资料拷进技能包。身份资料只在使用者主动请求、确认成品与使用范围后保存；默认不创建个人档案。

## 安装完成后，主动给用户的四项提示

先给下面的使用提示，再简要说明校验、备份和安装位置；不要先堆技术路径。

1. **是否要新开对话**：按实际宿主说明。需要刷新但尚未验证时，直接写“请新开一个对话再试；文件已安装，首次调用待验证”。不要一概声称无需刷新。
2. **怎样选技能**：若助手有“技能／使用技能”按钮，从列表选「min-开头」；选中后直接粘贴正文即可。没有该按钮时，发送下面的自然语言口令。只有实际支持斜杠选择器时，才把 `/min` 作为快捷选法，不要求所有用户学会 `/`。
3. **第一句直接复制**：

   > 用 min-开头，给下面这篇稿子写开头：
   >
   > 〔在这里粘贴你的完整正文〕

4. **什么结果算首次使用通过**：当前助手实际读取了 Skill 及必读参考，交出3个完整口播开头＋1个极简短版，并给出各自接回正文的位置或第一句。尚未用真实稿件调用时，标注“待首次使用验证”，不要把安装成功说成出稿已验证。

## 想加入自己的经历时，再使用身份梳理

这一步可选，不挡住正常写开头。直接发送：

> 帮我梳理开头身份，这是我的简介：
>
> 〔在这里粘贴你自己的简介、经历或旧稿；没有现成简介也可以直接说〕

预期先得到一句受众判断和三版不同用途、每条20字以内的身份短句；AI 应请你确认成品及公开／私域范围，再保存、读回。没有简介时按已有规则补问必要事实，不要求编数字或填满履历表。

你确认保存后，继续发：

> 这是我本人原创的稿件，按话题使用已保存的开头身份资料：
>
> 〔在这里粘贴正文〕

有合适资料才使用，通常至多在一个展开版中选一条；极简版不额外加个人身份。为朋友梳理时保存到其独立档案，不替换你的默认档；获准替朋友写其本人稿件时，使用保存后 AI 给出的对应人物调用用语。

## 从旧名「开头身份梳理」迁移

正式 Skill 名称与目录名现在统一为「min-开头身份梳理」。已有旧目录 `开头身份梳理/` 时，先核对其来源与已安装内容，确认它属于本产品，再按当前助手的实际目录规范迁移。

1. 将旧目录备份到技能扫描目录之外，保留可恢复副本；不要把旧目录和新目录同时留作已启用入口。
2. 保留目录外的 `user-profiles`、`private-libraries` 及其他私有资料，不因改名移动、覆盖或公开人物档案；已有归属、开关、使用范围和确认记录沿用。
3. 安装本包的完整 `min-开头身份梳理/` 目录，并按宿主实际情况调整旧入口或软链接；重新识别后核对列表中的正式名与实际路径，避免两个副本同时启用。
4. 遇到来源不明的旧目录、已有同名新目录或无法确认的自定义修改时，不直接覆盖；先说明冲突、现有安装范围与可行下一步。文件迁移完成不等于首次调用通过，仍按上方真实使用标准验收。

## 旧版更新时的区别

旧版 `scripts/skill_update.py apply` 只更新 `min-开头` 单目录；它运行成功不代表「min-开头身份梳理」也已安装。

如果此次通过旧“回复1”路径更新，结束引导应明确给出这段状态和下一步：“本次只更新了开头，未安装或验证身份梳理。你现在可以直接贴稿写开头；如此前未装身份技能，可复制官网当前完整安装口令，由AI助手校验完整包后补齐；此前已装的，按实际核验结果说明可用状态。遇到已有同名技能先核对来源，不直接覆盖。”随后给本次自然语言试用口令、素材占位和首用待验证状态。
想使用附带身份技能时，使用官网当前完整安装口令，由助手校验同一个正式完整包后补齐该目录；不擅自覆盖已有的其他同名技能。

开头仍保持原有“先完成当前任务、再提醒有更新、用户确认后才升级”的方式。每次安装或更新结束，主动结合本次新增或变化的功能给出一句可复制的自然语言试用口令、素材占位和预期结果。若此次只更新了开头，明确身份技能是否已安装及是否已实际调用；没有变化的功能不重复讲一遍。

新联动协议与个人资料槽分开：即使旧资料槽文件保留，当前开头也应读取新协议，再按归属、开关和范围决定是否使用已确认资料。备份、回滚和目录外私有资料保护仍按原更新器与本说明执行。

安装与日常使用不主动展示技术版本号；排障或用户主动问版本时可说明实际版本。联系敏敏沿用正式发行包的联系入口。
