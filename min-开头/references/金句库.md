# 金句与概念原境锻造指南（每次写/改开头必读）

> **最高纪律（严禁查库拼贴 · 原稿好词保真）**：
> 1. 本文件是**从当前原稿事实里原生锻造金句与概念词的工法引擎**，绝不是供检索抄袭的句子仓库！
> 2. **原稿原词优先铁律**：若当前原稿（尤其是作者原始输入段）本身已有锋利金句、直观裸算式、灵魂引号词或成对体感原话（如 `“A”的手感，“B”的爽感`），**直接原味完整保留作现成硬积木，严禁改水或截掉后半句**！
> 3. **金句定义**：被读者原句截图转走的社交货币——替目标受众一针见血说出他隐约察觉却一直没说出口的真相。重在穿透力与具体体感（短可七八字惊雷，长可三四十字结构洞察），严禁用工整空洞、无具体物支撑的「AI 对仗格言腔」充数。

## 一、工序 1：下笔前必过「去原词机制复述 ＋ Scale 通用靶子锁」（穿透在前，修辞在后）

本工序只服务于装配中已选中的金句或核心判断，不改变切入法、候选分工和前后搭建。原稿已有准确有力的句子时优先采用，不为造新句改水。严禁先挑句式填词，内部完成以下四问：
1. **剥壳问＋关系提炼**：不用现成行话或参考案例词，先用一句白话说清本稿值得说的判断、矛盾或立场，再确定**哪些对象在发生什么关系、依据是什么、哪些条件不能删**。
   - 从稿内找真正有意义的关系，例如区分相近概念、更换比较标准、同一动作换对象或范围、为了重要目标放下次要目标；选择材料支持的一种，不逐项套用。
   - 知识稿让关系帮助理解或选择；情绪稿让矛盾留在说话人的处境、口吻和意象中，不先概括成一条通用道理。没有依据的关系不补造。
   - 先比较关系是否值得说，再决定语序、重复、对照、反问或让步；本稿原词若已表达清楚，就保留。
2. **Scale 通用靶子锁（防造出小圈子窄金句！）**：供公域破圈席（候选 1 / 候选 4）调用的金句，其首句靶子动作**严禁锁在只有 1%～5% 同行才干的窄动作上**（如禁把首拍写成*“勤快日更救不了…”*）——必须抽成 **90% 普通人亲手干过的通用动作或世俗执念**（如：拼尽全力、点收藏、从头啃到尾、熬夜硬撑、年终表扬词）！
3. **词域问**：这篇原稿自己的真实世界里有哪些**具体动作、时间成本、金钱账目、直观算式、真实物件或关系角色**？（金句里的每一个名词和动词，必须优先从这些本稿自有词域中取！）
4. **全口播分腔问（按口播场合定语域，15字短气口零书面套嵌）**：
   - **穿透腔（短刀重锤感）**：适用于业务诊断、商业认知、方法机制揭示——重在挑破因果、算式与系统规则，一口气砸响；
   - **体感腔（活词画面感）**：适用于情绪共鸣、抗内耗自嘲、日常痛点口播——重在具体身体微动作与人情世故刺点；
   - **平视真话腔（去悬浮感）**：适用于 **态 C（私域 1v1 交底口播 / 语音说明信）**——重在坦诚反差与真实人生态度，**严禁卖弄居高临下的说教暴论或生造噱头黑话**。

## 二、工序 2：口播重锤压缩三律 ＆ 句级原境锻造五式（词句 100% 从本稿长出）

### 〇、口播重锤（Punchline）压缩三律（根治“罗列细碎名词没冲击力”！）
先把关系表达完整，再用以下三条压缩，不能为了响亮改变原意：
1. **重点早出，条件不丢**：让核心对象、动作和判断尽早出现，删掉无用铺垫；不强制使用全称或反叛断言，保留决定判断成立的对象、阶段与范围。
2. **关系有推进，不靠同义换词**：对照要让听众分清两件事、看见标准变化或理解取舍；不要求两端跨越不同世界。同一关键词在不同对象或范围上重复，若能让关系更清楚，应保留。
3. **具体可懂，按意思分气口**：优先使用原稿里准确的动名词与体感；抽象关系有明确对象且后文能解释，也可以直接说，不硬塞道具或比喻，不堆“赋能/闭环/抓手”等黑话。情绪张力服从本稿立场，不靠夸大语气补足判断。

根据已确定的关系，按需选用下列五种生成动作，或直接用自然口语表达；它们是表达工具，不是必须套满的句壳。**先保留意思，再按气口压缩，不统一把完整判断限为8～20字**；选用式5极短反判时仍按该子型的短句要求执行。只在走 `A1`、`A3` 金句/反判态或当前装配确需金句压阵时调用，写完交回原装配流程。

### 式 1｜本质重定义式（剥表象 · 立真核）
- **生成动作**：先指出受众在当前议题上表面看到的动作或指标，再一刀剥开它在真实利益链、时间账或成长路径里扮演的真正角色（`不是追求A，而是追求B` / `X的本质其实是Y`）。
- **走 A1 时的可选展开**：有真实两难或代价证据时，可由洞察展开到处境和后果；没有则保留判断及其必要说明，不硬凑句数。

### 式 2｜双系统规则对切式（拆两套玩法正面碰撞）
- **生成动作**：从原稿中提炼出两套截然相反的运行规则、评价标准或人群反应（如旧习惯的被动消耗 vs 新路径的主动复利，或同招在不同人群里的相反效果），让两套规则在同一维度上短促对撞。

### 式 3｜代价与因果倒转式（算清隐性时间/精力账本）
- **生成动作**：倒转受众习以为常的因果顺序——点破“不愿在主动目标上花某项小成本，就必然被迫在被动应付上赔掉数倍大成本”，或揭示“表面缺少的某项动作，其实是深层环境造成的规避反应”。

### 式 4｜以具体机制解释替代道德责备（归因须有稿内依据）
- **生成动作**：当原稿确有生理、环境或规则依据时，用具体机制解释替代“你太懒/不自律”的道德指责；若原稿仅有拖延、内耗等表象而无成因证据，保留真实感受即可，不凭空推断高感知力或保护本能。

### 式 5｜正词反判 / 贬词正面夺权惊雷式（极短首句破门刀 · 对应 A3-5）
- **生成动作**：当原稿核心论点直指某种“大众盲目追捧的正确姿势其实是低效陷阱”时，用 **8～15 字极短断言**直接把该正向词反判为消耗/愚蠢/负债；或反过来，替大众羞于启齿但本稿证明高效的具体做法理性正名。
- **配套铁律**：极短惊雷首句抛出后，**第 2 句必须立刻紧咬本稿的核心主张（要做什么、不做什么），并视信任赤字跟上直观算式或事实依据**，绝不允许只喊一句空暴论就悬空！

## 三、工序 3：词级原境凝练七法（供点题核块调用 · 新生造词严格限 ≤1 个！）

> **核心边界**：
> - **原稿自带好词全额保护**：若原稿本身已有精准好词或成对引号概念，直接原味提拔使用，**不受数量限制误杀**！
> - **AI 新生造词上限 ≤1 个**：原稿无现成概念且确需凝练时，单个开头最多只许新造 **1 个** 概念词，抛出后 **1～2 句内必须用具体动作或日常熟悉事物拆成大白话**！
> - **双向拆法与配重律**：可**正向先抛词再秒拆**，也可走**逆向倒装加冕式**（先用大白话描透人人经历却说不出的痛感，最后点名概念）或**大俗词高维重定义**；若前句用大白话/损失句起手，后句可跟一句浓缩判断做**人话→金句配重**。

1. **同域焊接法（抽象机制 × 本稿可感具体物）**：取本稿 1 个核心机制词与 1 个日常可感词做单次焊接（禁两个抽象词硬拼，禁借用阀门/闭环等工程黑话）。
2. **原生概念对法（A vs B 成对互训）**：原稿天然存在真假、先后、主被动对比时，提炼成短促对称的概念对，两极互解。
3. **状态觉察命名法（第一人称自嘲标签）**：给原稿中“人人经历却没名字”的微妙卡点起一个能直接自嘲的日常状态名。
4. **反差修饰焊法（矛盾张力词）**：把两个日常语义相悖、但在本稿情境下精准成立的日常词焊在一起。
5. **熟词新装法（低解码成本升维）**：借大众熟知的基础词，装进本稿具体场景赋予新解释。
6. **动词画面凝练法（动作＋对象成词）**：把原稿最关键的反差动作压缩成四到六字带画面的动词短语。
7. **向往身份序列 / 部落俱乐部命名法**：当原稿在讲阶段进阶或长期习惯时，把枯燥方法包装成受众心向往之的进阶身份序列或生活习惯部落名，紧跟进入该序列的第一个具体标志动作。

## 四、排毒红线（触犯任一条立即判 0 分重铸）

1. **换皮同义替换 ＝ 0 分**：把原稿利落大白话硬换成生硬比喻壳（既无认知增量又让人绕晕），一律剔除。
2. **输入法机械生造词 ＝ 0 分**：生造正常人说话绝不会用的拗口四字词或互联网黑话（如“赋能闭环、认知跃迁、生态抓手”）。
3. **跨语境捡现成金句 ＝ 0 分**：金句里的关键名词如果在当前原稿中找不到事实落点，再漂亮也是寄生异物，必须删除。
4. **转发双检不过 ＝ 退回白话**：写完自问「受众读到这句会有被戳中的爽感吗？」「比直接说短白话更有力吗？」否则直接用干脆白话直给，宁要真话短刀，不要工整假金句。
